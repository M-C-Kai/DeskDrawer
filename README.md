# DeskDrawer 桌面管理器

Windows 桌面整理工具，用 AutoHotkey v2 编写。把桌面图标按类型收进分区抽屉，桌面本身保持干净，没有传统应用窗口。

## 功能

- 6 个分区，按文件扩展名自动分类
- 系统分区：回收站、此电脑（CLSID 打开）
- 搜索桌面图标
- 一键整理
- 时钟小组件
- 拖动移动分区
- 毛玻璃开关（默认关闭，默认使用原始样式：壁纸原样透出）
- 设置通过 INI 文件持久化

## 使用

1. 安装 [AutoHotkey v2](https://www.autohotkey.com/)。
2. 运行 `DeskDrawer.ahk`。

首次运行会在脚本所在目录生成 INI 配置文件。

## 环境

- Windows 10 / 11
- AutoHotkey v2.0
